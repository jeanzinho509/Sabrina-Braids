# Imagens ilustrativas do catálogo

Geradas com a ferramenta integrada image_gen (sem CLI/API). Não representam clientes nem trabalhos realizados pelo salão. A interface identifica cada uma como “Imagem ilustrativa”. Substitua pelas fotos reais no admin quando estiverem disponíveis.

## box-braids

Arquivo: `apps/web/public/images/demo/box-braids.png`

Prompt final:

Use case: photorealistic-natural. Asset type: illustrative hairstyle catalog photo for a Brazilian braiding salon demo website. Subject: an adult Black woman wearing medium box braids: clearly visible square scalp partings and three-strand black braids, neatly installed. Composition: square image, back three-quarter head and shoulders view, all the crown in frame, hairstyle fills most of image, modest cream blouse. Backdrop: softly blurred warm beige salon wall. Soft daylight, realistic hair texture, professional hair catalog photography. No text, no logos, no watermark, no collage, one person only. This is a fictional illustrative model, not a salon client portfolio photograph.
